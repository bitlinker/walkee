# Architecture Decision Records — Walkee

Walkee — Android-игра для исследования города: карта, «туман войны», открываемый пройденными
маршрутами, ачивки и прогресс.

Здесь лежат зафиксированные архитектурные решения. Формат — [ADR](https://adr.github.io/):
контекст → решение → последствия. Решение не переписывается задним числом: если оно меняется,
пишется новый ADR, а старый помечается `Superseded by NNNN`.

| № | Решение | Статус |
|---|---------|--------|
| [0001](0001-grid-and-projection.md) | Сетка «пикселей» и проекция: пирамида тайлов Яндекса (EPSG:3395), хранение на z21, отображение квадратами z18 | Accepted |
| [0002](0002-fog-storage.md) | Структура данных тумана: разреженная битовая карта по чанкам z13 с quadkey-ключами, popcount-агрегатами и mip-уровнями | Accepted |
| [0003](0003-fog-rendering.md) | Рендер тумана через тайловый API MapKit (`addTileLayer`, PNG-тайлы, `DataSourceLayer.clear()`) | Accepted |
| [0004](0004-tech-stack.md) | Технологический стек и требования к коду | Accepted |
| [0005](0005-app-architecture.md) | Архитектура приложения: слои, redux-экраны, use case'ы, репозитории, рендереры | Accepted |

Соглашение: документация — на русском, код, комментарии и идентификаторы — на английском.
